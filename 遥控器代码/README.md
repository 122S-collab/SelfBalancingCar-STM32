# 两轮自平衡小车 — 遥控器代码

> 配套平衡小车的 NRF24L01 遥控手柄，基于 STM32F103C8T6，摇杆控制 + OLED 显示。

## 硬件平台

| 模块 | 型号/方案 | 说明 |
|------|-----------|------|
| 主控 | STM32F103C8T6 | Cortex-M3，72MHz |
| 摇杆 | 双轴摇杆 ×2 | ADC 采集（四通道） |
| 无线 | NRF24L01 | 2.4GHz 发送（软件 SPI） |
| 显示 | OLED 128×64 | I2C |
| 按键 | 轻触开关 ×2 | GPIO 输入 |

## 工作原理

1. ADC 定时采集两个摇杆的 X/Y 轴电压值
2. 映射为油门、偏航、俯仰、横滚四个控制量
3. 按键状态打包进数据帧
4. NRF24L01 2Mbps 无线发送至平衡车主控
5. OLED 实时显示摇杆位置和连接状态

## 通信协议

- NRF24L01，2Mbps 速率
- 5 字节地址，32 字节有效载荷
- 自动应答 + 自动重传
- 数据帧格式：`[ID, LH, LV, RH, RV, KEY]`

## 工程结构

```
遥控器代码/
├── Hardware/          # ADC / NRF24L01 / OLED / Key
├── System/            # 系统初始化 + Timer
├── User/              # main.c + 业务逻辑
├── Library/           # STM32 标准外设库
└── Start/             # 启动文件
```

## 开发环境

- Keil MDK-ARM
- STM32 标准外设库（非 HAL）
