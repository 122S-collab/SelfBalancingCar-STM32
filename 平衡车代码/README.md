# 两轮自平衡小车 — 平衡车代码

> 基于 STM32F103C8T6 的两轮自平衡小车，裸机开发，三环串级 PID + 互补滤波，支持无线遥控与蓝牙调参。

## 硬件平台

| 模块 | 型号/方案 | 说明 |
|------|-----------|------|
| 主控 | STM32F103C8T6 | Cortex-M3，72MHz |
| IMU | MPU6050 | 6 轴陀螺仪 + 加速度计（软件 I2C） |
| 编码器 | 正交编码器 ×2 | TIM3 / TIM4 编码器模式 |
| 电机 | 直流电机 ×2 | TB6612 H 桥驱动，PWM 调速 |
| 无线 | NRF24L01 | 2.4GHz 接收（软件 SPI） |
| 蓝牙 | BT04 / HC-05 | USART2，9600bps |
| 显示 | OLED 128×64 | I2C |

## 控制架构

### 三环串级 PID

```
角度环（外环，100Hz）→ 速度环（内环，20Hz）→ 电机 PWM
转向环（并联，差速控制）
```

### PID 参数

| 控制环 | Kp | Ki | Kd |
|--------|----|----|-----|
| 角度环 | 8.04 | 0.10 | 4.91 |
| 速度环 | 1.12 | 0.12 | — |
| 转向环 | 4.00 | 1.00 | — |

### PID 特点

- **微分先行**：对测量值微分，避免目标突变冲击
- **积分分离**：大偏差关积分，小偏差开积分
- **积分限幅 + 输出限幅**
- **死区补偿**（OutOffset）

### 姿态解算

```
倾角 = 0.02 × atan2(AY, AZ) + 0.98 × (Angle + Gyro·dt)
```

一阶互补滤波，加速度权 2%，陀螺仪权 98%。

### 系统时序

基于 TIM1 中断（1kHz）分频：

| 频率 | 执行内容 |
|------|----------|
| 1kHz | MPU6050 读取 + 姿态解算 + 角度环 PID + PWM 更新 |
| 200Hz | 编码器速度计算 + 速度环 PID + 转向环 PID |

> 角度超 ±50° 自动停机。

## 功能特性

- 直立平衡 + 无线遥控行走
- 蓝牙 APP 在线修改全部 PID 参数（Kp/Ki/Kd）
- OLED 实时显示角度、参数、占空比
- 软件 I2C / SPI 纯手写驱动

## 工程结构

```
平衡车代码/
├── Hardware/          # MPU6050 / Encoder / Motor / OLED
├── System/            # Timer + 中断服务
├── User/              # main.c + PID.c
├── Library/           # STM32 标准外设库
└── Start/             # 启动文件
```
